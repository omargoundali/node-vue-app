Sito per la gestione interna di un azienda:
 Come provarlo:
  1. entra nella cartella backend e avvialo:
      "cd backend", "node index.js"
  2. esci dalla cartella backend e entra nella cartella di frontend
      "cd ..", "cd frontend"
  3. Avvia il frontend
      "npm run server"
  4: entra su un browser e cerca "localhost:8080" (porta su cui è poggiato il frontend"
